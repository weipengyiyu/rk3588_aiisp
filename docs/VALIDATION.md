- BSP RAW 回读 ABI 核对通过：trigger 布局、ioctl 编号、线性触发模式和 little-aligned 存储模式。

## 尚未验证

本次新框架尚未完成板端 NPU 与 Sensor→ISP 联调。从本机连接原记录的板端 `192.168.1.61:22` 超时，从 SDK 主机连接时对端重置连接；当前会话也没有板端密码环境变量。本记录不沿用旧原型的板端帧率作为新框架实测数据。

旧 `external/imx623-aiisp` 的历史实测说明通路具备实现基础，但模块整理后的新产物仍须在可访问板端执行以下验收：

1. `--plan` 确认唯一匹配的线性 RAW12 拓扑。
2. bypass 至少 10 帧，RAW 文件位精确、YUV 帧号匹配、退出恢复。
3. rknn 至少 30 帧，核实 `npu_calls`、实际帧率与分阶段耗时。
4. 对同一输入运行 CPU 参考，用 `scripts/compare_raw.py` 比较 NPU 输出，示例模型阈值默认 2 个 RAW12 灰阶。
5. 检查 SIGINT、模型不匹配、超时后的恢复和重新运行。

自动 3A、Sensor IQ、生产画质、长稳、HDR、时域模型和实时目标均未列为已通过项目。
